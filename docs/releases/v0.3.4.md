# 课堂叮咚 v0.3.4

文字通知默认只显示不朗读；课堂倒计时可自由设定时长；修复手机上班级设置标签错位。

## 改动

- **朗读次数默认 0 遍**：发送文字通知时「朗读次数」默认为「不朗读」，可选 0–3 遍；原声通知改称「播放次数」，可选 1–3 遍。紧急通知的提示音仍单独设置。
- **倒计时自由设定**：课堂工具中的倒计时改为分、秒两个输入框，可设 1 秒至 120 分钟，并保留 1、3、5、10、15、30 分钟快捷按钮。
- **手机布局修复**：班级设置弹窗顶部的「教室大屏、协同老师、课堂工具、班级设置」在窄屏下改为两行显示，文字不再超出背景。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.3.4`。保留现有编排和数据卷，仅更新镜像后重建。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`。**大屏需升级到 v0.3.4** 才能识别「不朗读」；旧版大屏收到朗读 0 遍的通知时仍会朗读一遍。
