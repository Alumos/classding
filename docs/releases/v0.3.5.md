# 课堂叮咚 v0.3.5

学生可以在教室大屏的 Windows 桌面上点「呼叫老师」，二次确认后通知本班全部关联老师；老师在工作台「学生呼叫」中查看并共享处理。

## 新功能

- **桌面呼叫入口**：绑定后 Windows 桌面会显示「呼叫老师」原生悬浮入口，不占用任务栏。平时不抢焦点，点击后展开二次确认；取消或按 Escape 不发送，默认焦点在取消按钮。拖动可移到其他显示器，松手停在最近显示器工作区内并避开任务栏，按显示器缩放比例调整大小。
- **呼叫本班全部老师**：确认后由设备身份直接发送，不需要账号，也不会指定班级、老师或学生姓名。本班所有关联老师都会收到这条呼叫记录。
- **教师端「学生呼叫」**：教师工作台侧栏在「发通知」下方新增入口，未处理时显示红色数量。打开页面时提供网页在线提醒；断线重连或定时刷新后补齐，记录随服务持久化并包含在全站备份中。
- **共享已读**：任一位老师明确点开标记后，该条记录对其他老师同步为已处理，并保留处理老师与时间。仅浏览列表或进入页面不会自动标记已读。
- **防重复呼叫**：同一班级 30 秒内只能发起一次；连续点击时客户端显示剩余等待时间，服务端同时拦截。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.3.5`。保留现有编排和数据卷，仅更新镜像后重建。旧数据目录和旧版备份可以直接使用，缺少学生呼叫记录时会按空记录处理。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`。**大屏需升级到 v0.3.5** 才会出现桌面「呼叫老师」入口；教师端的学生呼叫页面也需要本版服务端。

## 已知限制

- 只在教师网页打开时提醒，不使用 Web Push，不承诺锁屏、关闭浏览器或手机后台时的提醒。
- 呼叫内容是固定提示，不含自由文本、录音或学生账号，也不提供回拨。
- 桌面悬浮入口的系统行为（多显示器、缩放比例、全屏覆盖、托盘、开机启动）仍需在真实 Windows 设备上验收。
- 同班 30 秒限流按班级计算，不做跨班级或跨设备合并。
