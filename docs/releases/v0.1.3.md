# 课堂叮咚 v0.1.3

改进教师通知与大屏阅读体验，增加系统外观设置、完整备份恢复和设备迁移。

- 通知时长直接选择 15 秒、30 秒、1/2/3/5/10 分钟。提示音默认关闭，紧急通知可由教师手动开启；语音朗读单独设置。
- 大屏常显“已读通知，关闭消息”按钮，可提前关闭并发送回执；新绑定默认名称为“班级名智慧黑板”。
- 教师和管理后台增加字号、提高文字对比度，兼容明暗模式和手机布局。
- 运营管理员在“系统配置”修改站点名称、备案号和主题，两个后台同步显示。
- 全站 ZIP 备份包含账号、班级、设备身份、消息、配置和录音。导入会覆盖当前数据，恢复后用户须重新登录，设备不必重新绑定。
- 设备管理支持单台和批量下发新站点地址；离线设备上线后可获取计划。客户端验证身份、消息序号和待播内容，重新获取录音签名后切换，保留原绑定。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.1.3`。1Panel 保留现有编排、数据卷、JWT_SECRET 和管理员密码，仅更新镜像后拉取重建。HTTP 直连保留 `COOKIE_SECURE: "false"`；HTTPS 可按现有配置使用 `true` 或可信代理下的 `auto`。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`，附 SHA256 校验文件；由 GitHub Actions 原生 Windows 构建，无需 QEMU。安装器尚未代码签名，需在实际教室电脑确认显示器、音量与托盘行为。升级安装时保留原程序的 data 目录。

## 换 IP 或域名

先安装 v0.1.3 客户端。先下发新地址计划，暂停旧站发送及其他写入，再导出最终备份并在新站恢复。新站在最终恢复前不要载入可接受旧设备令牌的旧备份。完成域名和 HTTPS 配置后，客户端定期验证并切换；未通过时继续使用旧站。两站不会实时增量同步，最终备份后不要继续向旧站写入。尚未收到计划的离线设备需要保留旧站可访问，直至它们取回计划。

备份文件包含密码哈希和设备凭据，请妥善保管。上传备份上限 256 MiB、解压后 512 MiB；导入覆盖前先下载当前站点备份。
