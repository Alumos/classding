# 课堂叮咚 v0.4.0

一次以稳定性和体验为主的大版本：桌面呼叫悬浮球不再挡住 PPT，大屏界面重新对齐并放大字号，教师端实时连接更稳，服务端更省资源。

## 大屏客户端

- **悬浮球不再始终置顶**：「呼叫老师」悬浮球处于普通窗口层级。PPT 放映、最大化的窗口会正常盖住它；回到桌面或在普通窗口旁仍可看到和点击。只有点击后展开的确认面板会提到最前。
- **更大更醒目**：悬浮球加大到 112×92（按缩放比例放大），橙色底、深橙描边、白色粗体大字「呼叫 / 老师」并居中；确认面板、标题、正文和按钮都同步加大。
- **界面对齐**：页眉、内容和页脚使用同一页宽，左右边缘对齐；「呼叫老师」卡片补齐样式并与悬浮球同色；正文、设置项、按钮字号整体加大；修复绑定页铃铛装饰压住步骤文字、卡片小标题上方多出横线的问题。
- **断网恢复更快**：连接 10 秒无响应会放弃并重试，不再长时间停在「正在连接」；Windows 报告网络恢复时立即重连。

## 教师与管理端

- 实时连接在心跳中续期登录令牌，不再每 15 分钟断开一次；重连后同时刷新作业、发送记录、班级、设备和学生呼叫。
- 发送记录分页改为「时间 + ID」，同一时刻发出的多条通知不会被漏掉。
- 撤回通知时，已经「失败」或「过期」的投递保留原状态。

## 服务端

- 密码哈希在全局锁外计算并限制并发，登录高峰不再拖慢大屏回执和其他请求；不存在的账号与密码错误耗时一致。
- 学生呼叫保留 90 天、审计日志保留 180 天，已用或过期的协作邀请自动清理，数据库不再无限增长。
- 写入按行编码、失败时从上次提交还原，每次写操作少一次整库序列化。
- 解绑屏幕时，未完成的投递立即标记为失败；教师建班时校验年级长度（最多 40 字）；发送过快的提示显示实际冷却秒数。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.4.0`。保留现有编排和数据卷，仅更新镜像后重建。旧数据库和旧版备份可直接使用；首次运行的定时清理会删除超出保留期的学生呼叫、审计记录和失效邀请。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`。悬浮球与界面调整需要**大屏升级到 v0.4.0**。

## 不兼容变更

- 移除了 0.1.3 之前共用的刷新 Cookie（`classding_refresh`）。只有从 0.1.2 及更早版本直接升级、且浏览器仍持有旧 Cookie 的用户需要重新登录一次。
- 发送记录的分页游标改为不透明字符串；直接调用接口的脚本应原样传回 `next_cursor`，不要自行构造时间戳。

## 已知限制

- 悬浮球层级、字号与界面对齐需在真实 Windows 设备（不同缩放比例、多显示器、PPT 放映）上验收。
- 学生呼叫仍只在教师网页打开时提醒，不使用 Web Push。
