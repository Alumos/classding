# 课堂叮咚 v0.3.0

新增界面字号调整、发送记录删除和设备内网地址显示；切换服务器改为直接生效；所有列表改为分页显示。

## 新功能

- **调整字号**：两个后台顶栏新增字号菜单（小 / 标准 / 大 / 特大），选择结果保存在各自账号上，换浏览器或电脑登录后仍然有效。
- **删除发送记录**：教师可删除自己发送或所管理班级的发送记录；管理后台「消息审计」可删除权限范围内的记录。尚未播放的通知会同时从教室大屏撤回。
- **设备内网 IP 与当前服务器**：大屏每次连接时上报本机内网 IPv4 地址和实际连接的服务器地址，在「设备管理」中显示，同时显示服务端看到的出口 IP。
- **分页**：激活码、教师、班级、设备、消息审计、操作日志、发送记录和作业列表全部分页显示，页面不再无限拉长。

## 切换服务器

- 「服务器切换计划」改为「切换服务器」：勾选一台或多台设备，填写新地址，在确认页核对后下发。
- 大屏收到新地址后立即切换，旧服务器后台显示为离线。
- 如果新服务器不认可设备，或 10 分钟内一直无法连接，大屏会自动回到原服务器，后台显示「切换失败，已回退」。尚未切换的设备可以撤销。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.3.0`。保留现有编排和数据卷，仅更新镜像后重建。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`。大屏需升级到 v0.3.0 才会上报内网 IP 并按新方式切换服务器；旧版大屏仍按原来的核验流程迁移。
