# 课堂叮咚 v0.1.4

修正两个后台切换页面时的布局跳动，统一页面宽度与对齐，并减少服务端空闲时的磁盘写入。

- 管理后台和教师工作台的侧栏固定为窗口高度，切换页面不再随内容拉长；账号与退出按钮始终显示在侧栏底部，侧栏内容过多时可单独滚动。
- 页面始终预留滚动条位置，长页面与短页面的内容宽度一致，在 Windows 等显示常规滚动条的系统上不再左右跳动。
- 页脚版权和备案号居中于内容区；教师「个人中心」与其他页面使用相同的内容宽度。
- 管理后台筛选栏的搜索框、下拉框、日期和按钮统一为 44px 高度；移除没有实际菜单的顶部下拉箭头和概览导航箭头。
- 教师侧栏账号区显示“教师”身份，长文字不再换行；版本号由构建自动带入，设备未上报版本时显示“版本未知”。
- 服务端维护任务在没有到期会话、通知或录音时跳过整库写入，避免每 30 秒持有全局锁重写数据。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.1.4`。保留现有编排、数据卷、JWT_SECRET 和管理员密码，仅更新镜像后拉取重建。本版本不改变数据格式。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`，附 SHA256 校验文件；由 GitHub Actions 原生 Windows 构建。本版本大屏端仅更新版本号，已安装 v0.1.3 的教室可按需升级。
