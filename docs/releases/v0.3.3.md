# 课堂叮咚 v0.3.3

教师工作台按班级成员身份开放班级；管理后台的列表支持按学校筛选。

## 改动

- **教师工作台只显示自己的班级**：管理员账号登录教师工作台时，只能看到和操作自己创建或协同的班级，不再列出所辖学校的全部班级。发通知、布置作业、课堂工具、撤回和删除通知都按同样的规则校验。管理所辖学校的全部班级请使用管理后台，后台权限不变。
- **按学校筛选**：管理后台的班级管理、设备管理、教师管理和激活码管理新增「按学校筛选」（运营管理员可见），分页、统计、导出和批量勾选都只针对筛选结果。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.3.3`。保留现有编排和数据卷，仅更新镜像后重建。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`。大屏端功能未变，v0.3.0 及以上的大屏可以继续使用。
