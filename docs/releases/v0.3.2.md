# 课堂叮咚 v0.3.2

新增学校管理，修复指定了学校的激活码无法兑换的问题；激活码支持批量删除。

## 学校管理

- 管理后台新增「学校管理」（仅运营管理员可见）：建立、改名和删除学校，查看每所学校的教师、班级和激活码数量。仍有教师、班级或激活码的学校不能删除。
- 教师、班级、激活码页面显示学校名称。生成激活码、创建或编辑教师时从列表选择学校。
- 运营管理员可以调整教师所属的学校，该教师负责的班级会一起转入。

## 修复

- 指定了学校的激活码此前无法兑换，提示「该激活码属于其他学校」。原因是自行注册的教师不属于任何学校。现在这样的教师兑换某校激活码后会自动加入该校，其负责的班级一并转入。
- 已属于另一所学校的教师仍不能兑换，提示会写明激活码和账号各自的学校名称。

## 批量删除激活码

- 在激活码表格中勾选后点「删除所选」即可批量删除。
- 正在被班级使用的激活码不能勾选，需先删除对应班级。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.3.2`。保留现有编排和数据卷，仅更新镜像后重建。

升级后，旧版本中手填过的学校 ID 会自动建成学校，暂以 ID 作为名称，可在「学校管理」中改名。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`。大屏端功能未变，v0.3.0 及以上的大屏可以继续使用。
