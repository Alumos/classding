# 课堂叮咚 v0.1.0

首版包含教师网页、管理后台、Go 服务端和 Windows 大屏客户端，提供账号与班级管理、设备绑定、文字和原声通知、发送记录、回执及激活码管理等核心流程。管理后台已完成本地试用。

## Windows 客户端

下载附件 `ClassDingScreen-amd64-installer.exe`，适用于 Windows amd64。安装包由 GitHub Actions 在原生 Windows 环境生成，采用当前用户安装方式。附件中的 `.sha256` 文件用于核对下载完整性。

安装包尚未进行代码签名，Windows 可能显示未知发布者。首次安装后请在目标教室测试 WebView2、系统中文语音、托盘、开机启动、音量恢复、多显示器及通知播报效果。

## Docker 服务端

镜像：`ghcr.io/alumos/classding-server:0.1.0`，仅支持 Linux amd64，无需 QEMU。部署配置见仓库 `deploy/README.md`；生产环境须配置独立密钥和管理员，持久化数据卷。

## 验证与范围

本地已通过三端类型检查和生产构建、大屏 9 项单元测试、10 项浏览器流程、Go 竞争检测测试，以及 Windows amd64 客户端交叉构建。云端构建结果请查看本版本对应的 GitHub Actions。

此版本使用单进程 SQLite 存储。学校管理与 Excel 导入、服务端语音识别和 TTS、自动更新、自动备份及大规模性能验证尚未完成。Windows 安装和系统集成需继续实机验收。
