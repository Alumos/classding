# 课堂叮咚 v0.1.2

修复部署后的登录与权限问题，补齐管理员对教师账号和班级的管理，并修复 Windows 安装器中文乱码。

- HTTP 部署刷新网页可保持登录；管理端与教师端分别保存会话，并发刷新不会相互踢出。
- 登录限流只统计错误凭据；管理员可在教师管理中解除登录限制。
- 管理员使用账号密码登录，无需动态验证码。已有账号、班级和数据库可直接升级。
- 后台支持教师账号新增、查询、编辑、密码重置、停用与删除；负责的班级须先转移或删除。
- 后台支持班级新增、查询、编辑、转移负责人、调整名额和删除；直接建班无需手填激活码。
- 修复通用激活码核销后组织归属，保留学校隔离；跨学校激活码会显示明确说明。
- HTTP 下复制激活码、协同码可降级使用；浏览器拒绝复制时可在弹窗内选中手动复制。
- Windows 安装脚本明确使用 UTF-8，修复安装标题和中文快捷方式名称乱码。

## 升级服务端

镜像：`ghcr.io/alumos/classding-server:0.1.2`，Linux amd64。1Panel 已有编排只需修改镜像版本，HTTP 直连增加 `COOKIE_SECURE: "false"`，删除 `ADMIN_TOTP_SECRET` 后拉取并重建。保留原有 JWT_SECRET、管理员密码、编排名称和数据卷，升级后重新登录一次。

HTTPS 反向代理部署可使用 `COOKIE_SECURE: "true"`；默认 `auto` 仅信任实际 TLS 或已配置可信代理的协议头。高位端口编排示例见 `deploy/compose.1panel.yaml`，可直接粘贴到 1Panel 编排编辑器并填写密钥与首次管理员密码，无需额外文件。

## Windows 客户端

下载附件 `ClassDingScreen-amd64-installer.exe`，适用于 Windows amd64，附 SHA256 文件。使用新版安装器升级；旧版已生成的乱码快捷方式可手动删除。构建运行于原生 Windows，无需 QEMU。安装器尚未代码签名，Windows 安装及教室系统集成仍需实机验收。
