# 课堂叮咚 v0.1.1

本版包含已合并的 TypeScript 7.0.2 升级。Windows 安装包和 Docker 服务端镜像均从 `v0.1.1` 标签重新构建，客户端、服务端和部署示例统一使用 0.1.1 版本号。

- 应用实际使用 TypeScript 7.0.2 进行类型检查和生产构建。
- REST 与 WebSocket 类型生成器使用独立的微软 TypeScript 6 API 兼容包，保持生成内容一致。
- CI、Windows 和 Docker 构建校验实际编译器版本及生成器 API。

## Windows 客户端

下载附件 `ClassDingScreen-amd64-installer.exe`，适用于 Windows amd64，采用当前用户安装方式；对应 `.sha256` 附件用于核对下载完整性。安装包由 GitHub Actions 在原生 Windows 环境生成，无需 QEMU。

安装包尚未进行代码签名。Windows 安装、WebView2、语音、托盘、开机启动、系统音量恢复和多显示器功能仍需在目标教室实机验收。

## Docker 服务端

镜像：`ghcr.io/alumos/classding-server:0.1.1`，仅支持 Linux amd64。`latest` 标签随本版更新。部署配置见仓库 `deploy/README.md`，生产环境须配置独立密钥、管理员和持久化数据卷。

本次为构建工具链升级与版本同步，首版核心功能及现有限制延续 v0.1.0。SQLite 数据目录只支持一个主服务进程，自动更新和自动备份尚未提供。
