# 课堂叮咚 v0.2.0

教师工作台和管理后台改用 shadcn/ui 全面重写，Windows 作业悬浮窗同步改版。

## 界面

- 两个后台改用 [shadcn/ui](https://ui.shadcn.com/)（Base UI 版本）组件重写，替换原有的自定义样式，界面风格与 shadcn 官网示例一致。
- 侧栏使用 shadcn Sidebar，可折叠为图标栏，固定在窗口内。手机端：管理后台使用横向导航条，教师工作台使用底部标签栏。
- 统一页面标题、卡片、表格、表单、下拉框、开关、标签页和确认弹窗；危险操作统一使用确认对话框。
- 深色模式跟随系统；站点主题（森林绿 / 海洋蓝 / 石板灰）只替换主色，其余沿用 shadcn 的中性色。
- 管理后台概览使用 shadcn Chart 绘制趋势图；表格支持键盘横向滚动，窄屏时显示滑动提示。
- 组件库结构、接口与行为约定见 `docs/WEB_UI.md`。

## Windows 作业悬浮窗

- Windows 11 使用系统圆角和细边框，Windows 10 使用圆角区域和窗口阴影。
- 学科色条和学科标签，显示教师姓名和更新时间；常见学科有固定颜色。
- 底部为带图标的圆角按钮，鼠标悬停时高亮并显示手形指针；长内容显示细滚动条和页码。
- 改为双缓冲绘制，滚动和悬停不再闪烁。仍只使用一个原生线程，不增加 WebView 或进程。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.2.0`。保留现有编排、数据卷、JWT_SECRET 和管理员密码，仅更新镜像后拉取重建。本版本不改变数据格式和接口。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`，附 SHA256 校验文件。作业悬浮窗的新外观需在教室电脑上实际确认。
