# 课堂叮咚 v0.3.1

整理全部代码，功能与界面和 v0.3.0 相同，接口保持兼容。

## 改动

- **主服务**：按职责拆分代码文件；每个接口在路由上写明访问级别，写操作的事务与回滚集中处理；角色和各类状态改为具名常量；班级、设备的存储字段与展示字段分开，人数、在线状态等实时信息不再写入数据库。
- **权限修正**：没有目标班级的通知，现在只有发送者可以撤回。
- **Windows 大屏客户端**：Go 代码按职责拆分；前端状态机提取公共步骤，删除不再使用的旧迁移状态。
- **教师端与管理后台**：改用自动生成的接口类型；两端的投递状态文案和颜色统一；删除未使用的组件和样式。
- **工程规范**：前端版本号统一取自根目录 `package.json`；引入 Prettier 统一格式，CI 检查前端与 Go 代码格式；新增 `docs/ARCHITECTURE.md` 说明代码结构。

## 升级

Linux amd64 镜像：`ghcr.io/alumos/classding-server:0.3.1`。保留现有编排和数据卷，仅更新镜像后重建。

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`。v0.3.0 的大屏可以继续使用，不必立即升级。

恢复备份时，备份文件外层仍严格校验，内部数据允许包含旧版本写入的多余字段，数据之间的关联校验不变。
