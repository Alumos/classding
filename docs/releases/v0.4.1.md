# 课堂叮咚 v0.4.1

大屏客户端界面更紧凑。只改大屏客户端的界面，服务端只更新了版本号。

## 大屏客户端

- **窗口更小**：默认窗口由 1180×760 缩小到 920×640，内容最大宽度 880。
- **排布更紧凑**：页眉、标题、卡片间距和内边距都收紧了。班级信息改为整行横条，左侧是班级名，右侧是“消息接收”和“班级音量”，不再留出大块空白。
- **卡片对齐**：「呼叫老师」与「声音测试」两张卡片并排，图标列和文字列对齐；设置项占满一行。窗口拉窄时自动变为单列。

## 升级

Windows amd64 安装包：`ClassDingScreen-amd64-installer.exe`，大屏升级到 v0.4.1 即可看到新界面。

服务端镜像 `ghcr.io/alumos/classding-server:0.4.1` 与 v0.4.0 功能相同，可以不升级；如果升级，只需替换镜像。

## 已知限制

- 主窗口大小、悬浮球层级和多显示器/缩放比例下的表现，需要在真实 Windows 设备上验收。
