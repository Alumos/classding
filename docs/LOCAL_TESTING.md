# 本地验收

管理后台已完成首版本地试用。以下步骤用于后续复测；Windows 安装与系统集成仍需目标设备验收。

## 管理后台

启动服务和管理页面：在仓库根目录分别运行 `pnpm dev:server`、`pnpm dev:admin`。

访问 `http://127.0.0.1:5174/admin/`，开发账号 `admin`，密码 `AdminDing2026!`。管理员使用账号密码登录，无需动态验证码。

建议依次操作：

1. 登录后查看工作概览、通知趋势和最近通知。
2. 进入激活码管理，生成两条带备注的激活码，按备注搜索、复制或导出 CSV。
3. 打开教师、班级和设备列表，确认数据来自本地服务。
4. 在教师端发送通知后，回到消息审计查看内容与回执，再查看操作日志。
5. 缩窄窗口，检查导航、表格和弹窗；表格内部可横向滚动。

演示数据保存在 `server/data/`，普通重启不会清空。自动浏览器验收使用独立临时数据库，不会改动这份数据。

## 教师与大屏联动

额外启动 `pnpm dev` 和 `pnpm dev:screen`，分别访问 `http://127.0.0.1:5173`、`http://127.0.0.1:5175`。

教师开发账号 `teacher`，密码 `ClassDing2026!`。在「我的班级」获取绑定码，在大屏页留空服务地址并输入绑定码。随后发送一条通知，查看大屏及发送记录。浏览器声音可能需要先点击测试播报；录音还需要浏览器和系统允许麦克风访问。

## 学生呼叫验收（未发布）

1. 给同一班级加入两位教师，并将 Windows 大屏绑定该班；确认桌面悬浮球出现。点击后取消，教师端不应产生记录；再次点击并确认发送。
2. 两位教师在线打开工作台时均应看到「学生呼叫」红色未读数量和提醒；进入页面不消除未读。任一教师手动标记已读后，两端同步消除该条未读，记录保留处理老师和时间。
3. 另一教师关闭页面期间发起呼叫，重新登录后仍可查看未读；重启服务、刷新网页后记录和已读状态保留。未加入班级的账号不得读取或处理该班记录。
4. 30 秒内新呼叫应提示稍后再试；断网不得显示发送成功，重试同一请求不产生重复记录。解绑后悬浮入口不可发送。
5. 在真实 Windows 上检查主窗口隐藏/托盘驻留、悬浮球拖动、多屏工作区与 DPI 缩放、确认/取消、发送中防重复、全屏通知期间隐藏及恢复。浏览器兜底入口和交叉编译不能替代这项实机验收。
6. 手机 320/390px、桌面及 150% 字号检查六项导航和未读徽标，不应溢出或遮挡操作。

- 浏览器验收覆盖电脑、平板和手机宽度的后台登录、图表、激活码生成及搜索、教师导航；电脑和手机另有真实绑定、200 字通知、回执和录音上传，新增 HTTP 会话保持、账号和班级管理、管理员解除登录限制、复制降级和并发刷新等流程。
