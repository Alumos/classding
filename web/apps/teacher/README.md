# 课堂叮咚教师端

教师端是 React 网页，提供登录注册、班级与成员管理、设备绑定、文字和原声通知、快捷短语、记录与回执、个人设置及课堂工具。班级操作和消息投递的权限、额度与状态由服务端校验和返回。

## 本地运行

在仓库根目录安装 Node.js 22.12 或更高版本、pnpm 11.25.0 和依赖，并在另一个终端启动服务：

```sh
pnpm install --frozen-lockfile
pnpm dev:server
```

再在仓库根目录运行：

```sh
pnpm dev
```

默认访问 `http://localhost:5173`。Vite 将 `/api`、`/ws` 转发到 `http://localhost:8080`；如需更换后端，启动教师端前设置 `CLASSDING_API_URL`。开发服务使用持久化的 `server/data/`，空数据目录预置教师账号 `teacher` / `ClassDing2026!`、两个班级，以及可用于新建班级的演示激活码 `TEST-2345`。已有同名账号和已使用的激活码不会因重启自动恢复。

可同时运行 `pnpm dev:screen` 打开大屏浏览器预览：教师端在班级详情获取 6 位绑定码，在大屏输入后发送文字通知，查看大屏显示和记录中的回执。浏览器预览不等于 Windows 客户端验收。演示账号仅供本地开发，勿用于生产。

## 当前行为

- 可向有权限的班级发送文字或上传原声，显示预览、发送记录及设备回执。离线消息只在有效期内等待补发。
- 录音依赖浏览器麦克风权限，最长 30 秒；当前发送原声，不提供服务端语音转文字。文本语音由大屏使用可用的系统语音播报。
- 页面有桌面和移动布局，但录音权限、微信内置浏览器及目标手机的显示和交互仍需实机验证。

检查与构建：

```sh
pnpm --filter @classding/teacher typecheck
pnpm --filter @classding/teacher build
pnpm test:e2e
```

浏览器测试需要安装 Playwright Chromium，且启动临时本地服务；完整验收步骤与发布前要求见 [项目说明](../../../README.md)。
