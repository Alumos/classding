# 课堂叮咚大屏端

Windows 10 及以上使用 Wails v2 / WebView2；前端也可以直接在浏览器中运行，便于开发和预览。大屏通过 6 位绑定码连接班级，接收通知并依次展示、播报。消息状态和待处理队列在本机保存，断线后按序号重新连接；撤回、解绑、倒计时和点名由服务端实时下发。

## 本地运行

在仓库根目录安装 Node.js 22+、pnpm 和工作区依赖，启动服务端，再运行：

```sh
pnpm --filter @classding/screen dev
```

访问 `http://localhost:5175`。留空服务器地址时，Vite 将 `/api` 和 `/ws` 转发至 `localhost:8080`。浏览器预览使用本地存储，令牌**未加密**，只适合开发；浏览器可能要求先点击“测试播报”，才能自动播放声音。浏览器版不会控制 Windows 系统音量或提供开机启动。

检查和构建前端：

```sh
pnpm --filter @classding/screen typecheck
pnpm --filter @classding/screen build
```

## Windows 构建与安装

需要 Go 1.26+、Node.js 22+、pnpm、Wails CLI v2.17.1、NSIS 和 WebView2 构建环境。在仓库根目录先执行 `pnpm install`，然后：

```powershell
cd screen
wails build -platform windows/amd64 -nsis -installscope user
```

生成的程序和安装包在 `screen/build/bin`。发布工作流会生成 `ClassDingScreen-amd64-installer.exe` 及对应 SHA-256 校验文件，并上传构建产物和版本 Release；当前构建未配置代码签名。安装脚本 `build/windows/installer/project.nsi` 须保存为带 BOM 的 UTF-8，Wails 生成的辅助脚本以 UTF-8 读取；请保留这两项设置，以确保安装界面及快捷方式的中文名称正确。工作流会检查源文件编码和安装包产品名称。安装脚本使用当前用户权限：优先检测可写的 D:、E: 盘，否则使用用户的 LocalAppData；仍可在安装时自行选择目录。WebView2 缺失时安装程序会运行 Wails 自带的引导程序。此配置尚未在 Windows 实机验证，系统策略或 WebView2 安装情况可能影响安装过程。

首次启动，输入学校管理员提供的 `http(s)://服务器地址`、设备名称和教师端的 6 位绑定码。保持程序运行即可接收消息。设备解绑请在教师端操作；收到解绑事件后大屏会清除本机令牌并返回绑定页。关闭窗口后程序会留在系统托盘继续接收；单击托盘图标可重新打开，右键菜单可打开或退出程序。通知和课堂工具出现时会临时显示窗口，结束后回到后台。托盘初始化失败时窗口会显示错误，关闭窗口将直接退出。

## 数据与系统行为

- Windows 将令牌、待播队列、消息 ID 和最后序号一起存放在安装目录的 `data/state.bin`，并使用当前用户的 Windows DPAPI 加密。请确保程序目录可写；DPAPI 数据与 Windows 用户和系统环境相关，重装系统或更换用户后可能需要重新绑定。非 Windows 开发构建不加密。
- 通知先持久化再发送送达回执；播放状态也在重连后重发。服务端须幂等处理重复回执。断线时后续待播消息等待重连确认后才播放，连接前会清除过期消息并在积压超过 4096 条时分批向服务端确认；请保持 Windows 日期和时间正确。设备崩溃发生在声音开始之后、已播放状态写入之前时，恢复后可能重播：物理声音与磁盘写入无法组成一个原子操作。
- 消息播放前通过 Windows Core Audio 读取输出设备音量与静音状态，写入恢复记录并设置班级音量，结束后恢复原设备；程序异常退出时下次启动尝试恢复。实现依赖系统 PowerShell 和 .NET，可能受学校策略限制；失败时显示错误并回报失败，需在目标设备实测。
- 开机启动同时注册当前用户 Run 项和“启动”文件夹快捷方式，并使用 `--silent` 在系统托盘静默待命；单实例锁防止重复启动。Windows 还原卡可能恢复注册表和启动目录，请将程序和自启配置加入保护例外。
- 可以在待命窗口选择通知和课堂工具使用的显示器，或让它跟随当前窗口；设置保存在安装目录的 `data/display.json`。显示器断开时回退到当前显示器并显示提示，显示器列表在窗口重新获得焦点时刷新。全屏置顶、不同缩放比例的多屏、PPT 和白板软件的覆盖效果需要 Windows 实机验证。
- 通知提示音默认关闭，只有紧急通知且教师主动勾选时才播放；随后优先播放服务端音频；音频失败时尝试用 WebView2/系统安装的中文语音朗读文本。声音、Windows 中文语音包、静音恢复和播放延迟需要在目标机器上测试。
- 卸载程序保留安装目录中的 `data`，包括加密令牌和队列；不再需要时可手动删除该目录。应先在教师端解绑，释放设备名额。

## 桌面作业窗

教师在工作台「布置作业」发布各科内容。Windows 使用真正的独立原生小窗口显示作业，默认在选定显示器的工作区右下角靠右排列，避开任务栏；未选显示器时跟随主窗口所在屏幕。最多每列四张，较矮屏幕自动减少行数，多余科目向左续列；4K 工作区按屏幕高度放大文字。长内容可滚动查看，也可在触摸屏点击正文翻页，翻到末页后再次点击返回开头。浏览器只提供预览列表。

每张作业窗提供置顶与隐藏按钮；客户端待命页可显示全部、隐藏全部或恢复后台设置。偏好保存在 `data/homework-local.json`，主窗口隐藏到托盘后仍生效。教师重新保存某条作业时，该条旧的本地覆盖会清除并应用新设置。通知或课堂工具全屏期间暂时隐藏作业窗，结束后恢复。删除、解绑或退出程序会清理窗口；当前作业快照随设备状态保存，断线重连补齐，每 30 秒校准一次。

作业包含在全站备份中；站点迁移还会核验作业修订号，拒绝明显落后的备份。换站时仍须按发布说明暂停旧站写入并恢复最终备份。

## 学生呼叫老师

绑定后 Windows 桌面左侧会显示橙色「呼叫老师」原生悬浮球（白色粗体大字）。它处在普通窗口层级，不会一直置顶：PPT 放映、最大化窗口会正常盖住它，回到桌面或其他窗口旁边时仍可见；主窗口关闭到托盘后仍可使用，不依赖网页中的浮层。拖动可移到其他显示器；松手停在最近显示器工作区内，避开任务栏，按显示器 DPI 调整大小。悬浮入口平时不抢焦点，只有点击展开二次确认时才激活；取消或 Escape 不发送，默认键盘焦点在取消按钮，Tab 可切换到确认按钮。全屏通知、课堂工具展示期间临时隐藏，结束后恢复，不移动或改变已有作业窗。

确认后由原有 WebView service 复用设备认证和 loopback 代理发送 `POST /api/v1/device/student-calls`，Go 原生层不保存另一份密钥。发送中禁止重复提交；成功须收到有效的服务器记录才显示「呼叫已发送」。本班所有关联老师在打开的教师网页收到提醒，任一老师标记已读后共享为已处理。服务端按同班 30 秒限流，客户端显示 `Retry-After` 等待时间。网络异常或响应丢失会显示结果未确认，用户主动重试沿用同一个幂等编号；不会离线排队或自动补发，退出程序后不保留未确认编号。

离线时保留入口供查看明确错误，确认按钮不可发送；解绑清理入口和未完成请求，再绑定不会接收旧绑定结果。请求超时和 WebView 无响应分别有服务请求/原生看门狗超时提示；客户端待命页另有相同二次确认的备用入口，浏览器预览仅提供备用入口，不会创建原生桌面窗口。

待 Windows 实机验收：主窗口关闭/静默托盘状态呼叫、鼠标和触屏点击/拖动边界、取消不发、键盘焦点与 Escape/Tab/Enter、断网及 401/403/429 错误、重试不重复、解绑中止、混合 DPI/负坐标多屏/任务栏工作区变化、全屏通知/课堂工具与作业窗恢复、退出清理 GDI 和窗口资源。交叉编译、Go 测试及浏览器测试不能替代上述实机检查。
